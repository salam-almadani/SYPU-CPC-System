# SYPU-CPC System

Programming Competition Management System - ASPU

---

## About the Project

This is our software engineering course project, where we developed a web-based system for managing programming competitions at the Arab Syrian Private University (ASPU). The main idea was to solve the problem of task organization and progress tracking between different teams, since each competition involves multiple teams (Technical, Organizational, Media) and it's difficult to track everything manually.

The system helps the competition manager distribute tasks to team leaders, who in turn break them down and assign them to team members. Each member can report any technical issues they face. There's also a dashboard that shows real-time completion rates.

---

## Key Features

- Competition management (create, edit, scheduling)
- Team and user management with role-based permissions
- Main task breakdown into subtasks
- Ticket system for technical issue reporting
- Interactive dashboard with completion rates
- Periodic and final reports in PDF format
- Real-time notifications on task updates
- Secure login and authentication

---

## User Roles

- **Competition Manager**: Full access to everything
- **Team Leaders**: Each leader manages their team and distributes tasks
- **Team Members**: Execute tasks and report issues
